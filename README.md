# PRIME AI Threads System

Агент, который сам ищет темы, пишет посты твоим голосом, публикует по расписанию,
отвечает на комментарии и учится на своей статистике.

Собрано из лучшего в открытых проектах (threads-skills, threads-growth-skill,
AK-Threads-Booster, autoTHREADS, threads-bot), пересобрано под русскоязычную нишу
и дополнено маркетинговой воронкой.

## Почему аккаунты берут миллион охвата за месяц

Не «вирусный пост». Три вещи вместе:

1. **Частота в правильных окнах.** 6 веток в день, но не размазанных: две утром,
   одна днём, две в прайм, одна перед сном. Жизнь ветки — часы, не сутки.
2. **Ротация форматов.** Набор дня 3 профессиональных + 1 широкая тема + 1 про себя
   + 1 свободная. Две утренние ветки всегда разных форматов.
3. **Ответы в первые 30 минут** плюс **5–10 комментариев под чужими ветками в день**:
   после комментария ты появляешься в ленте того человека.
4. **Серийная рубрика с номером** — люди подписываются на продолжение, а не на пост.

Всё остальное в системе обслуживает эти три вещи.

## Установка

В чате Claude Code:

```
/plugin marketplace add PRIME-AI-ACADEMY/prime-threads-system
/plugin install prime-threads-system@prime-threads
```

Дальше — `SETUP.md` (пошагово, с проверками).

## Как публикует

| Путь | Что нужно | Что даёт |
|---|---|---|
| **Postiz** ⭐ основной | аккаунт Postiz с каналом Threads + коннектор `https://mcp.postiz.com/mcp` в Claude | публикация из облака по расписанию, треды, медиа, первый комментарий |
| Threads Graph API — продвинутый | своё приложение Meta + токен (`GRAPH-API.md`) | + ответы на комментарии, статистика постов, обучение, автопилот |
| GitHub Actions — опционально | публичный репо `threads-cloud` (`CLOUD.md`) | публикация через API с закрытым ноутбуком, CDN для медиа |

## Порядок первого запуска

```
threads-setup  →  threads-dna  →  (threads-swipe)  →  threads-radar
      →  threads-plan  →  threads-write  →  threads-publish (черновик → расписание)
      →  threads-engage  →  через неделю threads-analytics  →  threads-autopilot
```

## Безопасность

- Токены только в `~/Claude/threads/.env` (chmod 600). Никогда в чат и не в git.
- Публикуется только то, что человек перевёл в `approved`.
- Первый запуск любого режима публикации — черновик (`type: "draft"`) или `--dry-run`.
- Система не выдумывает цифры, кейсы и результаты. Нет данных — спрашивает.

## Данные

Всё в `~/Claude/threads/` (или `$THREADS_HOME`) — профиль, банки, очередь, память.
Плагин можно переустанавливать, данные не трогаются. Скрипты — чистый Python 3 без
зависимостей; `ffmpeg` нужен только банку медиа.
