# Changelog

## 1.3.0 — 2026-09-25

Версия после боевого запуска (прогрев хакатона: 30 веток, 81 пост, все опубликованы).

### Добавлено
- **`threads-start`** — точка входа. Диагностика состояния и маршрут по одному шагу
  за раз, вместо списка из двенадцати скиллов.
- **`scripts/stats_log.py`** — аналитика БЕЗ Graph API. Замеры со скриншотов или
  из браузера, пересчёт весов по формулам, рубрикам, окнам и целям, отчёт за период.
  `threads-analytics` переписан под три режима: скриншоты (по умолчанию),
  браузер, Graph API (опционально).
- **`references/examples.md`** — восемь разобранных реальных веток из запуска,
  по одной на формат, с объяснением, почему каждая работает.
- **`evals/`** — 10 кейсов: маршрутизация скиллов и качество текста.
  Запуск: `claude plugin eval prime-threads-system@prime-threads`.
- `threads-engage`: честный ручной режим для работы без Graph API.
- `queue.py log` — журналирование веток, ушедших мимо очереди (режим Postiz).

### Исправлено
- **Проверка свежести была слепа в режиме Postiz.** Ветки уходили напрямую,
  в журнал не писались, и через пару недель система начала бы предлагать повторы.

## 1.2.0 — 2026-09-25

### Добавлено
- `references/formats-by-goal.md` — форматы веток по цели (подписки / охваты / продажи)
  из карты @gangstalav, перенесено полностью: полезные ветки в трёх форматах, результаты
  и достижения, сторителлинг, обработка инфоповодов, триггерные темы, ветка «Гроза»,
  ветки про продукт, ветки про востребованность, лайфхак с отметками.
- **Чек-лист из 10 эмоций** — обязательная проверка перед публикацией
  («О, это про меня», «Я хочу такой же результат», «Я не согласен» …).
  Подключён в `threads-write` как проверка 1.7.
- `hooks-ru.md`: **карта из 8 типов хуков** (результат, действие, интрига, боль,
  обещание, позиция, отрезвление, выгода) с формулами, примерами и таблицей
  «какой тип под какую цель».
- `check_posts.py --to-html` — конвертер plain text в HTML для Postiz.
- Инфоповоды подняты в `sources.md` и `threads-radar` как лучший источник охвата,
  с обязательным условием «позиция, а не пересказ».
- `rubrics.md`: раздел «Три цели и их доли» + еженедельное действие «попросить отметку».

### Исправлено
- **`check_posts.py` считал HTML-теги в лимит 500 знаков.** После перехода на HTML-формат
  Postiz ветка с 485 видимыми знаками ложно падала. Теперь длина считается по видимому
  тексту.
- **Проверки «есть ссылка» и «сказано, что бесплатно» применялись ко всем веткам.**
  Они были написаны под запуск и заваливали обычный контент. Теперь включаются только
  для веток про событие (определяется автоматически или полем `event`).
- **Проверка «пункт 1 в первом посте» применялась ко всем тредам.** Сюжетный тред
  без нумерации ложно падал. Теперь только для веток-списков (определяется по
  обещанию в открывающем посте или полем `kind: "list"`).
- Убран `scripts/__pycache__` из рабочей копии.

## 1.1.0 — 2026-09-26

Версия для участников практикума.

### Изменено
- **Postiz — основной путь публикации.** `threads-setup` и `threads-publish` переписаны:
  Postiz режим A, Threads Graph API — продвинутый режим B. Автопилот в режиме Postiz
  не требует задачи публикации.
- `threads-publish`: точная форма `integrationSchedulePostTool` по актуальной схеме
  (`content` в HTML с `<p>` на строку, `attachments` обязателен, `date` в UTC,
  `postsAndComments[0]` = пост, дальше комментарии). Добавлен эквивалент через Postiz CLI
  (`postiz posts:create -c … -c … -s <UTC> -t draft -i <id>`). Первый запуск — всегда черновик.
- `SETUP.md` переписан под участников: установка из GitHub-маркетплейса
  (`/plugin marketplace add PRIME-AI-ACADEMY/prime-threads-system`), Postiz по клику,
  первый запуск с проверками, Graph API — в свёрнутом «продвинутом» разделе.
- Рабочая папка данных настраивается через `THREADS_HOME` (по умолчанию `~/Claude/threads/`);
  `threads_api.py` теперь тоже читает её. `threads-setup` создаёт папку, если её нет.
- Пути к плагину в cron-примерах — через `${CLAUDE_PLUGIN_ROOT}` / путь установки,
  без привязки к домашней папке автора.
- Манифесты: версия 1.1.0, автор PRIME AI Academy, `homepage`/`repository`,
  версия плагина продублирована в `marketplace.json`.

### Добавлено
- `ФОРМАТЫ-ТРЕДОВ-памятка.md` — шпаргалка для раздатки: набор дня 3+1+1+1, 8 рубрик,
  окна публикации, 13 формул хуков, 5 правил анти-ИИ.
- `.gitignore`: `.env`, очередь, банки, профиль, память — не попадают в репозиторий.
- `CHANGELOG.md`.

### Убрано
- Личные пути автора из `CLOUD.md`.
