# Threads Media Bank — медиа с компьютера в облако

## Зачем это отдельный скилл

Threads Graph API принимает **только публичные URL**. Локальный файл опубликовать нельзя.
И облачная публикация (когда ноутбук закрыт) тем более не видит твой диск.
Поэтому медиа заливается заранее, а в очереди лежит ссылка, а не файл.

Практический смысл: раз в 3–5 дней пополняешь банк — дальше система крутит его сама,
даже когда компьютера нет рядом.

## Первый запуск

Проверь конфиг `~/Claude/threads/media.config.json`. Если его нет — спроси ник на GitHub
и создай (подробности в `CLOUD.md`):

```json
{
  "repo_path": "/Users/<user>/Claude/threads-cloud",
  "repo_slug": "<ник>/threads-cloud",
  "branch": "main",
  "cdn": "jsdelivr"
}
```

Без репозитория `threads-cloud` — сначала пройди `CLOUD.md`, шаг 1.

## Рабочий цикл

### 1. Посмотреть, что есть
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py scan
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py scan --source ~/Desktop
```
Источники: `~/Claude/threads/inbox/`, рабочий стол, папка скриншотов, папки проектов
(`~/Claude/reels`, `~/Claude/videos`). Спроси, откуда брать, если не сказано.

### 2. Посмотреть глазами и описать
**Это твоя работа, а не скрипта.** Прочитай каждый файл инструментом Read (картинки
показываются) и для каждого определи:
- теги: `скрин`, `дашборд`, `лицо`, `рабочее-место`, `результат`, `до-после`, `экран`, `быт`
- одно предложение описания — что на нём и к какому типу поста подойдёт
- **стоп-проверка приватности**: паспорт, банковские данные, чужие лица, адрес,
  переписка с личным. Такое не заливаем и прямо говорим почему.

### 3. Залить
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py ingest --tags "скрин,дашборд" --note "статистика за август"
```
Скрипт сам: сожмёт картинку до 2000 px и JPEG (< 8 МБ), перекодирует видео в
H.264/MP4 до 1080 px и 30 fps (< 20 МБ), **срежет все метаданные, включая геолокацию**,
отсеет дубли по хешу и запишет карточку в `bank/media.jsonl`.

Теги ставь пачками: заливай одинаковые файлы вместе, а не по одному.

### 4. Выложить в CDN
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py push
```
Коммит и push в `threads-cloud`. jsDelivr подхватывает новые файлы за 1–10 минут.
**Проверь первую ссылку в браузере в режиме инкогнито** — если файл не открывается
у незалогиненного человека, Meta его тоже не заберёт.

### 5. Подбор под пост (это делает `threads-plan`, не человек)
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py pick --tags скрин --kind image
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py use --id m-64d470 --post 2026-09-09T09-00-1
```
`pick` берёт наименее использованное подходящее медиа — банк не крутит одну картинку.

## Что не проходит и почему

| Файл | Проблема | Решение |
|---|---|---|
| видео длиннее 5 минут | лимит Threads | нарезать на куски по 15–40 с |
| видео не жмётся до 20 МБ | слишком длинное или детальное | укоротить клип |
| HEIC с айфона | Threads не принимает | конвертируется автоматически в JPEG |
| скрин с личными данными | приватность | не заливать, сказать пользователю |

## Норма банка

- **≥ 30 свободных единиц** — на неделю работы завода хватает.
- Меньше 10 свободных → скажи об этом и попроси пополнить, не жди, пока кончится.
- Соотношение: примерно 70% картинок и скринов, 30% коротких видео.

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/media_bank.py list --unused
```

## Чего не надо заливать

Сток, безликие «руки над ноутбуком», картинки-иллюстрации ни о чём. Визуал на Threads
работает как **доказательство или наглядность**. Если он ни то и ни другое —
пост сильнее без него.

Соседние скиллы: `threads-visual` (создать визуал с нуля), `threads-plan` (подбор под слот)
