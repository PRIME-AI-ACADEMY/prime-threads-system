# Threads Radar — поиск тем, которые не кончаются

Цель прохода: **20–40 тем со скором ≥ 6** в банк. Этого хватает на 2–3 дня работы завода.

## Порядок обхода (сверху вниз, останавливайся, когда набрала норму)

### 1. Свой архив — самый дешёвый источник
Прочитай, что уже есть: `~/Claude/*.md`, папки проектов, контент-планы, конспекты уроков,
скрипты рилсов, карусели. **Одна карусель = 5–8 тем.** Каждый слайд может стать постом.
Ищи: цифры, кейсы, пошаговые разборы, ошибки.

### 2. Комментарии и вопросы (самый конверсионный)
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/threads_api.py mine --limit 25
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/threads_api.py replies --to <media_id>
```
Каждый вопрос под своим постом = тема. Плюс вопросы из директа/учеников, которые
пользователь скинет. Помечай такие темы `"source": "question"` — у них приоритет.

### 3. Конкуренты и ниша
Через `threads-swipe` (или скиллом `agent-reach`, если нужен веб-обход).
Забирай **угол и структуру**, не текст. Если не можешь добавить свой опыт — не бери тему.

### 4. Тренды и новости
WebSearch по нише за последние 1–3 дня: релизы инструментов, изменения площадок, новости рынка.
Формула темы: `новость + что это меняет лично для моей аудитории`. Срок годности — двое суток,
такие темы ставь в план первыми.

### 5. Свои процессы сегодня
Спроси одним вопросом: «Что ты сегодня сделала, сломала, починила или посчитала?»
Это рубрика «кухня» — самая честная и самая дешёвая.

### 6. Возражения из `profile/dna.md`
Каждое возражение = минимум один пост. 15 возражений = 15 постов, снимающих барьер к покупке.

### 7. Банк вечнозелёных
`~/Claude/threads/bank/topics.jsonl`, записи со статусом `evergreen`. Поднимай под новым углом.

## Скоринг (0–10)

| Критерий | Баллы |
|---|---|
| Боль острая и названа словами аудитории | 3 |
| Есть мой личный опыт / цифра / доказательство | 3 |
| Тема не поднималась 14 дней | 2 |
| Ясна формула хука под неё | 1 |
| Ведёт к продукту (пусть далеко) | 1 |

**< 6 — не в план**, а в `evergreen`.

## Проверка свежести — обязательна

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/queue.py fresh --topic "формулировка темы" --days 14
```
Совпадение темы **и** угла за 14 дней → отклонить. Та же тема, другой угол → можно,
пометить `"angle_repeat": true`.

## Что записать

Дописывай в `~/Claude/threads/bank/topics.jsonl` по строке на тему:
```json
{"id":"t-2026-09-08-01","topic":"почему автопостинг умирает на 2-й неделе","angle":"кончаются идеи, а не инструменты","source":"own-process","rubric":"мнение","formula":"T1","goal":"replies","score":9,"evidence":"мой опыт: 3 попытки, 2 сдохли","status":"ready","created":"2026-09-08"}
```

## Выдача пользователю

Не вываливай JSON. Покажи таблицу: тема | угол | рубрика | формула | скор | откуда.
Отсортируй по скору. Спроси, какие убрать, и предложи следующий шаг — `threads-plan`.
