# Threads Analytics — обучение на своих данных

Через 3–4 недели система должна писать под **её** аудиторию, а не по общей теории.
Этот скилл — контур обратной связи, который это делает.

## 1. Сбор

```bash
# посты за период
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/threads_api.py mine --limit 100 --since 2026-09-01
# метрики поста: views, likes, replies, reposts, quotes, shares
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/threads_api.py insights --media <media_id>
# метрики аккаунта + подписчики
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/threads_api.py account-insights --since 2026-09-01
```

Соедини метрики с записями `queue/published.jsonl` по `published_id` — так у каждой
цифры появляется формула, рубрика, час и формат.

## 2. Что считать

**Главная метрика — не просмотры, а «вес разговора»:**

```
engagement_score = replies*30 + shares*5 + reposts*3 + quotes*3 + likes*1
er = engagement_score / views
```

Веса взяты из силы сигналов алгоритма: комментарий стоит примерно 30 лайков,
пересылка 3–5, репост — «сохранение».

**Отдельно считай отправки (shares).** На реальных ветках их бывает в 10 раз больше,
чем репостов (107 против 10 при 39 400 просмотров). Это главный канал распространения,
и он же лучший предиктор роста подписок.

**И главную метрику — подписки с ветки.** Охват без подписок не растит аккаунт.
На той же ветке: 39 400 просмотров → 88 подписок. Считай `подписок / 1000 просмотров`
по каждому формату, это честнее, чем ER.

**Срезы (каждый — таблица со средним ER и средними просмотрами):**
1. по формуле хука (T1–T13),
2. по рубрике,
3. по часу и **по окну** (утро 07–10 / день / прайм 18–21 / перед сном),
4. по формату (одиночный / тред / фото / видео / карусель),
5. по цели (replies / reposts / likes / quotes),
6. по длине текста (до 150 / 150–300 / 300–500),
7. **по типу из набора дня**: профессиональная польза / широкая тема / про себя / тест.

Ожидаемая картина, которую подтверждает практика: личные истории дают самый большой
охват (173 тыс. против 39 тыс. у экспертного списка), а списки и советы дают подписки.
Если у тебя не так — это ценная находка, зафиксируй её в `notes`.

Минимум **5 постов** в срезе, иначе не делать выводов — это шум.

## 3. Пересчёт весов

Обнови `~/Claude/threads/memory/patterns.json`:
```json
{
  "updated": "2026-09-15",
  "n_posts": 87,
  "formula_weights": {"T11": 1.6, "T3": 1.4, "T13": 1.2, "T5": 1.0, "T6": 0.7},
  "rubric_weights": {"цифры": 1.5, "кухня": 1.3, "мнение": 1.1, "оффер": 0.4},
  "best_hours": ["08:30", "09:30", "18:00", "21:00"],
  "best_windows": {"утро": 1.6, "день": 0.6, "прайм": 1.4, "перед_сном": 1.1},
  "subs_per_1k_views": {"список": 2.2, "история": 0.4, "хвастовство": 1.8},
  "worst_hours": ["15:00"],
  "best_format": "single+screenshot",
  "avg_er": 0.041,
  "notes": ["посты с личной цифрой в первой строке дают ×2 комментариев",
            "треды длиннее 6 постов теряют половину аудитории к 4-му"]
}
```

Вес = средний ER среза / средний ER аккаунта. `threads-write` и `threads-plan`
читают эти веса и отдают приоритет формулам > 1.2, а формулы < 0.7 берут не чаще
одного раза в 20 постов.

## 4. Недельный отчёт (в `memory/weekly/YYYY-WW.md` и в чат)

```
НЕДЕЛЯ {даты}
Постов: {N} · Просмотры: {сумма} ({±% к прошлой}) · Подписчики: {+N}
Средний ER: {x} ({±%}) · Комментариев на пост: {x}

ТОП-3 поста: {первая строка | формула | просмотры | комментарии | почему сработало}
ХУДШИЕ 3: {то же | гипотеза, почему не пошло}

СРАБОТАЛО: {формулы/рубрики/часы с весом > 1.2}
НЕ СРАБОТАЛО: {вес < 0.7}

ВОРОНКА: клики в профиль {N} · новые подписчики TG {N} · заявки {N}

РЕШЕНИЯ НА СЛЕДУЮЩУЮ НЕДЕЛЮ (3–5 штук, конкретные):
1. …
```

**Отчёт без решений бесполезен.** Каждый вывод должен превращаться в изменение
в `patterns.json`, `rubrics.md` или в сетке слотов.

## 5. Тревожные сигналы

| Симптом | Причина | Действие |
|---|---|---|
| Просмотры падают неделя к неделе | усталость аудитории, повтор тем | усилить ротацию рубрик, снизить частоту на 25% |
| Просмотры есть, комментариев нет | посты закрывают мысль, нет приглашения | больше T3/T9/T1, вопрос в финале |
| Комментарии есть, подписок нет | непонятно, чем ты полезна дальше | переписать шапку и закреп, добавить рубрику-разбор |
| Подписки есть, заявок нет | сломана воронка, а не контент | `funnel.md`: CTA, лид-магнит, закреп |
| Резкий обвал всего | red line или спам-флаг | проверить последние 10 постов по red lines |
