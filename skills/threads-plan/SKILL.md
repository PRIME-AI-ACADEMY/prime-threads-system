# Threads Plan — сетка публикаций

Задача: превратить банк тем в очередь с точными слотами, где ни одна рубрика
не идёт дважды подряд, а воронка соблюдена.

## 1. Сетка окон — не «равномерно по дню»

**Читай `${CLAUDE_PLUGIN_ROOT}/references/rhythm-windows.md` перед каждой раскладкой.**
Слоты не размазываются равномерно, они собраны в четыре окна разной силы.

| Окно | Веток | Сила | Что ставим |
|---|---|---|---|
| 07:00–10:00 | **2**, разрыв 30–60 мин | максимум | самое сильное: инструкция/лайфхак, затем **другой формат** (мнение или результаты) |
| День (13:00–16:00) | **1** | слабое | короткая мысль, наблюдение, юмор, тест |
| 18:00–21:00 | **2** | максимум | ~18:00 короткий список лайфхаков, ~21:00 длинная ветка с большими советами |
| Перед сном (22:00–23:00) | **1** | разговорное | спорное мнение, инфоповод, история |

**Базовый режим: 6 веток в день, 6 дней в неделю, суббота выходная.**
Диапазон 5–8 веток. Больше — только на запуске и с предупреждением о рисках.

Жёсткие правила времени:
- пауза между ветками **от 20 минут**, подряд не публикуем;
- две утренние ветки **обязательно разных форматов**;
- самое важное **никогда не днём**.

Часовой пояс — по ядру аудитории, не по себе.

## 1.5. Набор дня: 3 + 1 + 1 + 1

| Сколько | Тип | Обычное окно |
|---|---|---|
| 3 | профессиональная польза | утро ×1, прайм ×2 |
| 1 | широкая тема (жиза, юмор, инфоповод) | день или перед сном |
| 1 | про себя и ценности | утро, вторая ветка |
| 1 | свободный тест | день |

Плюс серийная рубрика с номером в заголовке идёт **каждый день в одно и то же окно** —
она и есть скелет плана.

## 2. Правила раскладки (жёсткие)

- Не две одинаковые рубрики подряд, особенно две утренние.
- Минимум 4 разных формата в сутки.
- Оффер — не чаще 1 на 10 веток и никогда первой веткой дня.
- 70–80% веток по теме блога, 20–30% про себя.
- Пропорция целей за неделю: **replies 40% · reposts 35% · likes 15% · quotes 10%**.
- Пропорция воронки на каждые 10 постов: **5 польза · 3 личность · 1 доказательство · 1 оффер**.
- Утренние слоты — польза и разборы. Вечерние — личность, узнавание, истории.
- Чередование форматов: не больше 3 текстовых подряд без визуала.

## 3. Проверка свежести перед каждой постановкой

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/queue.py fresh --topic "тема" --days 14
```
Есть коллизия → взять следующую тему из банка, эту вернуть в `evergreen`.

## 4. Наполнение

Для каждого слота: тема из банка (по убыванию скора) → рубрика → формула → цель →
`threads-write` пишет текст → `threads-visual`, если формат требует медиа →
запись в очередь со статусом `draft`.

Пакетно:
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/queue.py add --file /tmp/day.json   # массив записей
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/queue.py list --day 2026-09-08
```

## 5. Подтверждение

Покажи план дня таблицей:

| Время | Рубрика | Формула | Цель | Первая строка | Прогноз |
|---|---|---|---|---|---|

Спроси: утвердить всё / поправить конкретные / переписать хуки.
После «ок»:
```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/queue.py approve --all-day 2026-09-08
```

**Публикует не этот скилл, а `threads-publish` / `threads-autopilot`.**
Статус `approved` — это разрешение на публикацию, выданное человеком.

## 6. Горизонт

Планируй на 2–3 дня вперёд, не на месяц: тренды протухают, а обратная связь
из `threads-analytics` должна успевать влиять на следующие посты.
Исключение — вечнозелёные рубрики, их можно набить на неделю.
