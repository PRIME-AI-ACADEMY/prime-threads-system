# Настройка PRIME AI Threads System — за один вечер

Делай по порядку. После каждого шага — проверка ✅. Если проверка не сошлась — не иди дальше,
напиши в чат поддержки практикума, что именно не сошлось.

Тебе нужны: аккаунт Threads, Claude Code (`claude` в терминале), аккаунт Postiz (бесплатный старт).
Ничего программировать не надо. Python 3 на Mac уже есть, ставить библиотеки не нужно.

---

## Шаг 1. Установить плагин (3 минуты)

Открой терминал, напиши `claude`, дождись приглашения. Дальше две команды **прямо в чат Claude**:

```
/plugin marketplace add PRIME-AI-ACADEMY/prime-threads-system
/plugin install prime-threads-system@prime-threads
```

✅ Проверка: набери `/plugin` → в списке есть `prime-threads-system`, 12 скиллов `threads-*`.
Если нет — перезапусти `claude` и проверь ещё раз.

Обновить потом: `/plugin marketplace update prime-threads` → `/plugin update prime-threads-system@prime-threads`.

---

## Шаг 2. Подключить Threads к Postiz (5 минут)

Postiz — это «почтальон»: он хранит расписание и сам публикует в Threads из своего облака,
даже когда твой ноутбук закрыт.

1. Открой [postiz.com](https://postiz.com) → **Sign up** (почта или Google).
2. Внутри слева **Launches** → кнопка **Add channel** (плюс).
3. Выбери **Threads** → откроется окно Instagram/Threads → войди тем аккаунтом, который ведёшь → **Allow**.
4. Вернёшься в Postiz: слева появился кружок с аватаркой твоего Threads.

✅ Проверка: в Postiz есть канал Threads, кружок не серый и без надписи «disabled».

---

## Шаг 3. Подключить Postiz к Claude (3 минуты)

Чтобы Claude мог ставить посты в расписание, ему нужен «мостик» — коннектор.

1. Открой [claude.ai](https://claude.ai) → внизу слева свой аватар → **Settings** → **Connectors**.
2. Кнопка **Add custom connector**.
3. Name: `Postiz`. URL: `https://mcp.postiz.com/mcp`. → **Add**.
4. Нажми **Connect** рядом с Postiz → откроется вход в Postiz → войди → **Allow**.
5. Закрой и заново открой `claude` в терминале (коннекторы подтягиваются при старте).

✅ Проверка: в Settings → Connectors у Postiz статус **Connected**.
✅ Проверка в чате: напиши `покажи мои каналы в postiz` → Claude вызовет `integrationList`
и покажет строку с `threads`.

Если Claude говорит, что инструментов Postiz нет: перезапусти `claude`; если не помогло —
терминал: `claude mcp add --transport http postiz https://mcp.postiz.com/mcp` и снова `claude`.

---

## Шаг 4. Первый запуск системы (10 минут)

Пиши в чат ровно эти фразы, по одной, дожидайся ответа.

**4.1 «настрой threads»** → скилл `threads-setup`
Создаст рабочую папку `~/Claude/threads/`, найдёт твой канал в Postiz, поставит один тестовый
пост **черновиком** (в Threads он не уйдёт).
✅ В ответе таблица: режим `postiz`, имя канала, папка создана, следующий шаг `threads-dna`.

**4.2 «собери threads dna»** → скилл `threads-dna`
Интервью на 10–15 минут: ниша, для кого, как ты говоришь, что продаёшь, рубрики.
Отвечай своими словами, без «правильных» ответов — это твой голос.
✅ В `~/Claude/threads/profile/` появились `dna.md`, `voice.md`, `funnel.md`, `rubrics.md`.

**4.3 «найди темы на неделю»** → скилл `threads-radar` (по желанию перед ним «разбери конкурентов в threads»)
✅ В ответе 20+ тем со скором, лучшие ≥ 7.

**4.4 «собери контент-план threads на завтра»** → скилл `threads-plan`
✅ Таблица на 6 веток: время · рубрика · формула · хук. Набор 3+1+1+1 (см. памятку).

**4.5 «напиши посты по плану»** → скилл `threads-write`
Каждый пост придёт с тремя вариантами хука. Выбирай, правь, говори «ок» или «перепиши».
✅ Все посты в очереди со статусом `draft`, ты прочитала каждый.

**4.6 «утверди план на завтра и поставь в postiz черновиком»** → скилл `threads-publish`, режим draft
✅ В ответе ссылки `previewUrl`, в Postiz → Launches в календаре видны черновики на завтра.
Открой один — проверь, что текст цел, время твоё (Claude переводит его в UTC сам).

**4.7 «всё верно, ставь в расписание»**
✅ В Postiz черновики стали запланированными (цветной статус). Утром они уйдут сами.

**4.8 Через 20–30 минут после первого поста** — зайди в Threads и ответь на комментарии.
Это самый сильный сигнал для алгоритма, и в режиме Postiz его делаешь ты.

---

## Шаг 5. Ежедневный ритм (15 минут вечером)

```
вечером:  «собери план на завтра»  →  читаешь  →  «ок, в расписание»
утром:    ответить на комментарии в первые 30 минут после каждой ветки
          + 5–10 осмысленных комментариев под чужими ветками
воскр.:   «разбери неделю в threads» — что залетело, что нет, что меняем
```

Первую неделю — только с твоей проверкой каждого поста. Потом «поставь threads на автопилот»
(`threads-autopilot`), уровень 1 или 2.

---

## Где лежат твои данные

`~/Claude/threads/` — профиль, темы, очередь, статистика. Плагин можно удалять и ставить заново,
папка не трогается. Хочешь другую папку — перед запуском `claude` задай `export THREADS_HOME=~/путь`.

## Частые проблемы

| Что видишь | Причина | Что делать |
|---|---|---|
| `/plugin install` не находит | маркетплейс не добавлен или опечатка | повтори шаг 1, имена точно как написано |
| Claude не видит Postiz | коннектор не подключён / не перезапущен `claude` | шаг 3, п. 4–5 |
| В `integrationList` нет threads | канал не добавлен в Postiz | шаг 2 |
| Пост встал не в то время | часовые пояса | Postiz хранит UTC; скажи Claude свой город, он пересчитает |
| Postiz вернул `errors` | >500 знаков, не тот id канала, ссылка на картинку не публичная | Claude покажет текст ошибки и исправит |
| Картинка не прикрепилась | локальный файл вместо ссылки | медиа только через банк (`пополни банк медиа`) или `uploadFromUrlTool` |
| Посты уходят, охвата нет | red lines или дубли тем | `references/algorithm-2026.md`, проверь последние 10 постов |

<summary><b>Продвинутый уровень: Threads Graph API (ответы, статистика, автопилот без Postiz)</b></summary>

Postiz закрывает публикацию. Три вещи через него не работают: автоответы на комментарии
(`threads-engage`), статистика каждого поста (`threads-analytics` учится на ней) и почасовой
автопилот без Postiz. Для них нужен собственный токен Threads API.

Это 20–30 минут один раз, бесплатно, но требует создать приложение в
[developers.facebook.com](https://developers.facebook.com). Пошагово — **`GRAPH-API.md`**
(скрипт `scripts/get_token.py` делает техническую часть). Токен живёт 60 дней, кладётся в
`~/Claude/threads/.env` и никуда больше.

Режимы совместимы: публикуешь через Postiz, комментарии и инсайты читаешь через API.
Публикация с закрытым ноутбуком без Postiz — `CLOUD.md` (GitHub Actions).

</details>
