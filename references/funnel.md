# Воронка Threads: от охвата к деньгам

Threads — это **верх воронки**. Здесь не продают. Здесь собирают внимание и уводят
в среду, где можно продавать (Telegram, Instagram-директ, лид-магнит, вебинар).

## Лестница

```
Threads (охват, бесплатно)
   ↓ узнавание за 5–15 касаний
Профиль (шапка = один оффер + одна ссылка)
   ↓
Лид-магнит / Telegram-канал (контакт)
   ↓ прогрев
Трипваер (низкий чек)
   ↓
Основной продукт
```

## Правило 5-3-1-1 (распределение постов в неделю по цели)

Из каждых 10 постов:
- **5 — польза** (T5, T7, T10, T13). Задача: подписка и репост.
- **3 — личность / мнение** (T1, T3, T6, T11, T12). Задача: разговор и доверие.
- **1 — соц. доказательство** (кейс, результат ученика, скрин). Задача: снять «а работает ли».
- **1 — оффер** (мягкий, с CTA). Задача: перевести в контакт.

Больше одного продающего поста на 10 — падает охват и растут отписки.

## CTA, которые не режут охват

Threads душит прямой engagement bait и ссылки в первом посте. Работают:

| Тип | Формулировка | Куда ведёт |
|---|---|---|
| Вопрос-разговор | «А у тебя что из этого уже стоит?» | комментарии (главный сигнал) |
| Разрешение спросить | «Спроси в комментариях — разберу твой случай» | комментарии → директ |
| Ссылка ответом | Пост без ссылки → **своим первым комментарием** «Разбор целиком — в закрепе профиля» | профиль / TG |
| Ключевое слово | «Напиши в комментарии слово СИСТЕМА — пришлю схему» | директ (мягкая форма, не «пиши +») |
| Профиль | «Всё, что я строю, — в шапке» | профиль |

**Никогда:** «лайк, если согласна», «репостни», «подпишись, чтобы не потерять».

## Что должно быть в профиле (иначе охват не конвертируется)

1. Строка «кто я + для кого + результат» — без «эксперт, наставник, ментор».
2. **Одна** ссылка. Не «мультиссылка на 8 кнопок».
3. Закреплённый пост = лучший разбор + мягкий переход.
4. Аватар, по которому тебя узнают в маленьком кружке ленты.

## Метрика воронки (считать еженедельно)

| Уровень | Метрика | Норма |
|---|---|---|
| Охват | просмотры / пост | растёт неделя к неделе |
| Вовлечение | комментарии / пост | ≥ 3 на пост = здоровый |
| Переход | клики в профиль / просмотры | ≥ 1% |
| Контакт | новые подписчики TG / неделя | цель по бизнес-плану |
| Деньги | заявки → продажи | из business-dna |

Если охват растёт, а контактов нет — сломана не система постинга, а профиль и CTA.
